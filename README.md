# Zhaumbie's Unofficial Submods for Just Natsuki
This is the public compilation of all my unofficial submods (and their repos) for the DDLC mod [Just Natsuki](https://justnatsuki.club/).

> **Personal Note:** Every submod I write is designed to complement the official release, not undermine it or dismiss its features. I'm outspoken in my respect for the developers and their vision and prioritize content I believe they'd build if only they had the time.
> 
> Always always [always back up your persistent file](https://github.com/Just-Natsuki-Team/NatsukiModDev/wiki/04:-FAQ#can-i-back-up-my-save-data--how-do-i-find-my-persistent), and don't bother the JN Team for submod tech support—bother me!

## Major Submods
- **[Post-Game Content (BETA)](https://github.com/Zhaumbie/Post-Game-Content-for-Just-Natsuki):** a new post-game featuring new locations, living conversations with Natsuki, and much more... stay tuned
- **[No More Amnesia](https://github.com/Zhaumbie/No-More-Amnesia-for-Just-Natsuki):** huge continuity memory upgrades to build a better, stronger relationship with Natsuki going forwards
- **Unannounced:** a major idle/habit overhaul system in development since September... stay tuned!
- **Unannounced:** a major dialogue overhaul system in development since January... stay tuned!

## Features, Added
- **[Custom Holiday—JNiversary](https://github.com/Zhaumbie/JNiversary-for-Just-Natsuki):** A new heartfelt holiday event celebrating the day you met Natsuki (7–10 minutes)
- **[Ichi](https://github.com/Zhaumbie/Ichi-for-Just-Natsuki):** UNO-inspired card minigame with multiple game modes and competitive, reactive banter galore

## Features, Improved
- **[Modern Activity Detection](https://github.com/Zhaumbie/Modern-Activity-Detection-for-Just-Natsuki/):** modernizes and widely upgrades Natsuki's recognized apps/programs/websites, including fixing some vanilla typos and errors—and re-enables the entire feature for macOS (finally!)
- **[Music Playlists](https://github.com/Zhaumbie/Music-Playlists-for-Just-Natsuki):** because looping ONE song is ***so*** 2017

## Utilities and Bug Fixes
- **[Fix macOS Log](https://github.com/Zhaumbie/Fix-Broken-Log-macOS-for-Just-Natsuki):** no longer must we macOS users fly totally blind on the affinity system
- **[Fix Special Characters](https://github.com/Zhaumbie/Fix-Special-Characters-for-Just-Natsuki):** repairing busted characters in custom music tracks, like those damn hyphens!
- **[JN Unofficial Patch](https://github.com/Zhaumbie/Just-Natsuki-Unofficial-Patch/):** bug fix patch repairing Issues raised on the official GitHub while the devs are MIA
- **Persistent Plus (In Progress):** safeguarding persistent bloat from unused Ren'Py record book-keeping
- **[Bonus: Expression Previewer (for submodders)](https://zhaumbie.github.io/Expression-Previewer-for-Just-Natsuki/):** adds shuffle functionality to the official JN Expression Previewer
